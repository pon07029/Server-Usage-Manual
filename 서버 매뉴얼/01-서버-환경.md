## 디스크 및 데이터 위치

| 마운트 | 장치 / 파일시스템 | 용도 |
|---|---|---|
| `/` | `/dev/sdb3`, ext4, `df -h` 기준 약 849G | OS, `/home`, 시스템 로그 |
| `/boot/efi` | `/dev/sdb1`, vfat, 약 1.1G | EFI 부팅 |
| `/data` | `/dev/sda1`, XFS, 약 88T | 연구 데이터, 공용 도구, Docker 저장소 |

확인 당시 `/` 사용률은 약 90%, `/data`는 약 69%였습니다. 수치는 실시간으로 변합니다. 대용량 결과는 관리자가 지정한 `/data` 프로젝트 경로에 저장합니다. `/home`과 `/tmp`도 루트 디스크를 소모합니다.

```bash
df -hT / /data /boot/efi
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINTS
findmnt /data
du -sh "$HOME"
```

추가 NTFS 디스크는 확인 당시 마운트되지 않았습니다. 데이터 경로나 백업 대상으로 사용 중이라고 간주하지 않습니다. RAID 구성·복구 가능성은 별도 검증이 필요합니다.

공용 도구는 `/data/00_tools`, Docker 데이터는 `/data/00_tools/docker`에 있습니다. 공용 경로 전체의 소유자·권한을 일괄 변경하지 않습니다.

## 실행 중인 주요 서비스

| 기능 | 서비스 |
|---|---|
| 접속 | `ssh`, `xrdp`, `xrdp-sesman` |
| 스케줄러 | `munge`, `slurmctld`, `slurmd` (자동 시작도 활성) |
| 웹 | `nginx`, `rstudio-server`, `shiny-server`, `php8.2-fpm` |
| DB / 컨테이너 | `mysql` / `docker`, `containerd` |
| GUI | `gdm`; 기본 디스플레이 관리자 `/usr/sbin/gdm3` |
| 로그·접근 보호 | `rsyslog`, `fail2ban`; UFW 활성 |
| 기타 | Tailscale, NFS 관련 서비스, Postfix |

NFS 관련 서비스는 실행 중이지만 `exportfs -v` 결과 활성 export가 없었습니다. Tailscale·NFS·메일의 이용 권한과 외부 도달성은 관리자에게 확인합니다. 서비스 실행·포트 수신 상태만으로 외부 접속 성공을 보장하지 않습니다.

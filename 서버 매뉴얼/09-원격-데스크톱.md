# 원격 데스크톱

[목차](../README.md)

## 현재 구성

- 기본 디스플레이 관리자: `/usr/sbin/gdm3`, `gdm` 서비스 실행 중.
- Ubuntu 및 Ubuntu on Xorg 세션 파일이 존재합니다.
- XRDP 0.9.17, `xrdp`·`xrdp-sesman` 실행 중, TCP 3389 수신 확인.
- LightDM은 사용 중이 아니며 VNC 서버 실행 파일·서비스는 이번 점검에서 확인되지 않았습니다.

## 접속

Windows의 원격 데스크톱 연결에서 관리자가 알려 준 `SERVER:3389`에 접속합니다. 개인 Linux 계정으로 로그인하며 세션 선택 화면이 있다면 Xorg를 선택합니다. SSH 공개키가 RDP 로그인 비밀번호를 대신하지는 않습니다.

외부 3389 접근이 제한된 경우 PC에서 SSH 터널을 연 뒤 `localhost:13389`로 접속합니다.

```bash
ssh -N -L 13389:127.0.0.1:3389 -p 22 USERNAME@SERVER
```

서비스·포트 수신은 확인했으나 GUI 로그인과 화면 렌더링을 직접 검증하지 않았습니다.

## 관리자 확인

```bash
systemctl status gdm xrdp xrdp-sesman --no-pager
sudo journalctl -u xrdp -u xrdp-sesman -n 80 --no-pager
sudo tail -n 50 /var/log/xrdp.log
sudo tail -n 50 /var/log/xrdp-sesman.log
```

검은 화면이나 세션 종료는 계정 권한·동일 계정의 기존 GUI 로그인·세션 로그를 확인합니다. 기존 세션을 확인하지 않고 GDM/XRDP를 재시작하지 않습니다.

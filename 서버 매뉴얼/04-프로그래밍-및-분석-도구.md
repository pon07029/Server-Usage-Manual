# 프로그래밍 및 분석 도구

[목차](../README.md) · 2026-10-24에 root 비대화형 셸과 설치 경로를 확인했습니다. 개인 PATH·Conda 환경은 다를 수 있습니다.

## 확인된 환경

| 환경 | 버전 / 경로 |
|---|---|
| Python | `/usr/bin/python3`, 3.10.12; 기본 `python` 명령은 확인되지 않음 |
| R / Rscript | `/usr/bin/R`, `/usr/bin/Rscript`, R 4.4.2 |
| Conda | 여러 사용자 홈의 `miniconda3` 등에 개별 설치; 공용 root PATH에는 없음 |
| Node.js | `/usr/bin/node`, v21.7.3 |
| PHP CLI | `/usr/bin/php`, 8.3.3 |
| PHP-FPM | `/usr/sbin/php-fpm8.2`, 8.2.15; 서비스 실행 중 |
| Go | `/usr/local/go/bin/go`, go1.22.0; root 기본 PATH에는 없음 |
| CUDA 컴파일러 | `/usr/bin/nvcc`, CUDA 11.5 / V11.5.119 |
| GPU 드라이버 | 555.58.02, A10 1개 |

시스템 버전을 바꾸기 전에 기존 서비스 의존성을 확인합니다. PHP CLI와 FPM은 버전이 다릅니다.

```bash
command -v python3 R Rscript node php nvcc
python3 --version
R --version
node --version
php --version
/usr/local/go/bin/go version
nvcc --version
nvidia-smi
```

`nvidia-smi`의 CUDA 표시는 드라이버가 지원하는 수준입니다. 설치된 컴파일러는 `nvcc --version`으로 확인합니다. PyTorch·TensorFlow·cuDNN의 설치 여부와 버전은 사용할 개인 환경에서 별도 확인합니다.

## Python 가상환경

`python3-venv`와 `python3-pip`가 설치돼 있습니다. 본인 프로젝트에서 환경을 만듭니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip --version
# 프로젝트에 requirements.txt가 있는 경우
python -m pip install -r requirements.txt
```

Slurm에서는 환경 Python의 절대 경로나 명시적인 활성화를 사용합니다. 시스템 Python에 `sudo pip install`로 패키지를 덮어쓰지 않습니다.

## Conda

자신의 계정에 설치된 Conda를 사용합니다. 다른 사용자의 홈을 공용 설치처럼 참조하지 않습니다.

```bash
command -v conda
# 본인의 설치 경로가 아래와 같은 경우
source "$HOME/miniconda3/etc/profile.d/conda.sh"
conda env list
conda activate MYENV
command -v python
```

배치 작업은 대화형 셸 초기화를 가정하지 않습니다. `source`와 `conda activate`를 스크립트에 넣거나 환경 실행 파일의 절대 경로를 사용합니다.

## R

```bash
Rscript -e 'print(R.version.string); print(.libPaths())'
Rscript analysis.R
```

개인 라이브러리나 프로젝트에서 패키지를 관리합니다. RStudio Server도 `/usr/bin/R`을 사용하도록 설정돼 있습니다. 무거운 분석은 [Slurm](05-Slurm-작업-실행.md)에서 실행합니다.

## 공용 분석 도구

아래 실행 파일의 존재와 실행 권한을 확인했습니다. 분석 정확성과 모든 종속 라이브러리를 검증한 것은 아닙니다. 디렉터리 이름의 버전은 실행 시 다시 확인합니다.

| 도구 | 실행 파일 |
|---|---|
| SAMtools | `/data/00_tools/samtools-1.19.2/samtools` |
| BCFtools | `/data/00_tools/bcftools-1.19/bcftools` |
| bgzip / tabix | `/data/00_tools/htslib-1.19.1/bgzip`, `/data/00_tools/htslib-1.19.1/tabix` |
| PLINK | `/data/00_tools/plink_linux_x86_64_20231018/plink` |
| PLINK 2 | `/data/00_tools/plink2_linux_avx2_20231123/plink2` |
| BOLT-LMM | `/data/00_tools/BOLT-LMM_v2.4.1/bolt` |

PATH에 없으면 절대 경로를 사용합니다. BWA-MEM2 등은 실행 중인 분석에서 관찰됐지만 공용 명령 경로는 확인되지 않아 경로를 임의로 지정하지 않습니다. 프로젝트별 환경과 실행 스크립트를 확인합니다.
